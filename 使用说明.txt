            库存积压时长监控系统 — 使用说明
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 系统概述
───────────────────────────────────────────────────────

本系统通过摄像头实时监控库存区域，自动识别并跟踪每个物料的
停留时间（积压时长），帮助管理人员及时发现长期积压的物料。

核心功能：
  · 实时视频画面 + 目标检测框
  · 每个物料独立跟踪，显示积压时长
  · 颜色警示（绿/黄/红）快速识别异常积压
  · 历史数据统计


2. 快速开始
───────────────────────────────────────────────────────

2.1 安装依赖
  打开终端（命令提示符），进入项目目录后执行：

      pip install -r backend/requirements.txt

  首次运行会自动下载 YOLOv8 模型文件（约 6MB）。

2.2 启动系统

  a) 使用电脑摄像头（测试用）：
        python backend/main.py

  b) 使用单路网络摄像头（RTSP 协议）：
        set CAMERA_RTSP_URL=rtsp://用户名:密码@192.168.1.100:554/stream
        python backend/main.py

  c) 使用多路摄像机（同时监控多个角度）：
        set CAMERA_SOURCES=0,rtsp://admin:pass@192.168.1.101:554/stream,rtsp://192.168.1.102:554/stream
        python backend/main.py

  d) 使用视频文件（演示用）：
        set CAMERA_SOURCES=视频1.mp4,视频2.mp4
        python backend/main.py

2.3 打开监控界面
  启动后，打开浏览器访问：
      http://localhost:8000

3.1 顶部状态栏
  · 连接状态：显示 WebSocket 连接状态（已连接/连接中/已断开）
  · 对象计数：当前筛选条件下的物料数量
  · ⚙ 设置按钮：打开设置窗口，管理摄像头和积压阈值（见第 5 章）

3.2 摄像机切换标签（视频上方）
  · 点击标签切换查看不同摄像头的实时画面
  · 当前选中的摄像头标签高亮显示
  · 视频画面和检测框对应所选摄像机
  · 通过设置窗口添加/删除摄像头后，标签会自动更新

3.3 实时视频画面
  · 在左侧显示选中摄像头的实时画面
  · 每个检测到的物体会被矩形框标出（颜色对应积压等级）
  · 框上方显示 "CamX-ID:X 积压时长"

3.4 物料卡片列表（右侧）
  · 顶部 [All] / [Cam 1] / [Cam 2] ... 标签用于筛选对象
  · 选择 "All" 查看所有摄像头的物料
  · 每个被跟踪的物料显示为一张卡片，包含：
  · 缩略图：物料的实时小图
  · 摄像机标签：显示来自哪路摄像机
  · ID：唯一标识编号
  · 积压时长：格式为 "天:小时:分钟"，每分钟更新
  · 状态标签：Normal（正常）/ Watch（关注）/ Alert（警报）
  · 卡片边框颜色随积压等级变化
  · 缩略图底部有色条指示状态

3.5 图例
  🟢 绿色  < 3天  — 正常
  🟡 黄色  3-6天  — 需要关注
  🔴 红色  > 6天  — 积压超标，需要处理

3.6 底部统计栏
  · Total logged：历史累计跟踪过的物料总数
  · Avg dwell：所有物料平均积压时长
  · Max dwell：所有物料中最大积压时长
  · Cameras：接入的摄像机总数


4. 积压时长与颜色警示
───────────────────────────────────────────────────────

4.1 积压计算规则
  · 物料首次进入画面时开始计时
  · 积压时长 = 当前时间 − 首次出现时间
  · 若物料离开画面后重新出现，会分配新 ID 并重新计时
  · 积压时长显示格式：D:HH:MM（天:小时:分钟）
    例如：0:03:45（3小时45分钟），5:12:30（5天12小时30分钟）

4.2 颜色警示阈值

   ┌──────────┬────────────┬──────────┬──────────┐
   │  等级     │  积压时长   │ 边框颜色  │ 状态标签  │
   ├──────────┼────────────┼──────────┼──────────┤
   │ 🟢 正常  │  < 3 天    │  绿色    │  Normal  │
   │ 🟡 关注  │  3 ~ 6 天  │  黄色    │  Watch   │
   │ 🔴 警报  │  > 6 天    │  红色    │  Alert   │
   └──────────┴────────────┴──────────┴──────────┘

  颜色变化会同时体现在：
  · 卡片的外边框
  · 缩略图底部的颜色条
  · 状态标签的背景色和文字颜色
  · 视频画面中的检测框颜色


5. 配置设置
───────────────────────────────────────────────────────

5.1 通过界面设置
  点击右上角 ⚙ 设置按钮，打开设置窗口，包含两部分：

  a) 摄像头管理（Camera Management）
     · 列表显示所有已接入的摄像头：名称、视频源、运行状态
     · 添加：在输入框填写 RTSP 地址（或本地摄像头索引，如 0），
       点击 "Add Camera"（或按回车）立即生效
     · 删除：点击摄像头右侧 "Remove" 按钮并确认，该摄像头的
       视频流线程会停止，相关积压记录关闭
     · 摄像头配置自动保存到 backend/cameras.json，重启后保留

  b) 积压阈值（Alert Thresholds）
     · 单位为小时（输入框旁已标注 "hours"）
     · Green < ：绿色阈值（小时），默认 72（3天）
     · Yellow <：黄色阈值（小时），默认 144（6天）
     · 修改后点击 Apply 立即生效（所有摄像头共用）
     · 支持小数，如 0.5 表示半小时

5.2 通过环境变量设置（启动前）

  ┌─────────────────────┬──────────────┬─────────────────────────────────────────────┐
  │ 环境变量             │ 默认值        │ 说明                                         │
  ├─────────────────────┼──────────────┼─────────────────────────────────────────────┤
  │ CAMERA_SOURCES      │ 0 (摄像头)    │ 逗号分隔的摄像机列表，如 0,rtsp://...        │
  │ CAMERA_RTSP_URL     │ 0 (摄像头)    │ 单路 RTSP（CAMERA_SOURCES 未设置时启用）    │
  │ PROCESS_WIDTH       │ 640          │ 处理分辨率宽度                               │
  │ PROCESS_HEIGHT      │ 480          │ 处理分辨率高度                               │
  │ CONF_THRESHOLD      │ 0.5          │ YOLO 检测置信度阈值                          │
  │ ALERT_GREEN_MAX     │ 259200       │ 绿色阈值（秒），默认 3天                     │
  │ ALERT_YELLOW_MAX    │ 518400       │ 黄色阈值（秒），默认 6天                     │
  │ YOLO_MODEL          │ yolov8n.pt   │ YOLOv8 模型变体                              │
  │ DEVICE              │ cpu          │ 推理设备 cpu 或 cuda                        │
  │ HOST                │ 0.0.0.0      │ 服务绑定地址                                 │
  │ PORT                │ 8000         │ 服务端口                                     │
  └─────────────────────┴──────────────┴─────────────────────────────────────────────┘

  设置示例（调整积压阈值为 1天/2天）：
      set ALERT_GREEN_MAX=86400
      set ALERT_YELLOW_MAX=172800
      python backend/main.py

  注意：若 backend/cameras.json 已存在（通过界面添加/删除过摄像头），
  启动时以该文件中的摄像头列表为准；环境变量（CAMERA_SOURCES /
  CAMERA_RTSP_URL）仅在配置文件不存在时生效。

  ┌──────────────────┬──────────────────────────────────┐
  │ 接口              │ 说明                             │

    "alert_color": "#ef4444",

7. 常见问题
───────────────────────────────────────────────────────

Q: 页面显示 "Disconnected"？
A: 确认后端已启动且网络正常，系统会自动重连。

Q: 视频画面卡住不动？
A: 检查摄像头连接是否正常，RTSP 地址是否正确。

Q: 检测不到任何物料？
A: 调整摄像头角度，确保有物体在画面中移动。
   可降低 CONF_THRESHOLD（如 0.3）提高检测灵敏度。

Q: 积压时长不刷新？
A: 前端每 60 秒刷新显示，WebSocket 持续推送数据。
   如果长时间不更新，请刷新页面重新连接。

Q: 积压阈值如何调整为小时级（测试用）？
A: 点击 ⚙ 在设置窗口中修改阈值（单位：小时），例如：
   绿色 < 1（1小时），黄色 < 4（4小时）
   或通过环境变量设置（单位：秒，如 ALERT_GREEN_MAX=3600）。

Q: 如何添加一路新的网络摄像头（RTSP）？
A: 点击右上角 ⚙ 设置 → 在 "Camera Management" 输入框填写
   RTSP 地址（如 rtsp://user:pass@192.168.1.100:554/stream），
   点击 Add Camera，界面立即出现新的摄像头标签。

Q: 删除摄像头后配置会保留吗？
A: 会。摄像头列表保存在 backend/cameras.json，删除后重启
   服务器不会再出现该摄像头。


8. 技术架构（简要）
───────────────────────────────────────────────────────

  ┌──────────┐   YOLOv8+SORT    ┌────────────┐
  │ 摄像头    │ ───────────────→ │ 后端检测跟踪 │
  └──────────┘                  │ (Python)    │
                                │ FastAPI     │
                                └────┬───────┘
                       WebSocket ────┤
                       MJPEG  ───────┤
                       REST API ─────┤
                                ┌────▼───────┐
                                │ 前端展示    │
                                │ (浏览器)    │
                                └────────────┘

  · 后端：Python + FastAPI + YOLOv8 + SORT 跟踪
  · 前端：纯静态 HTML/CSS/JS，通过 WebSocket 接收实时数据
  · 存储：SQLite 记录每次物料的出现和离开事件
  · 摄像头管理：界面可动态添加/删除摄像头，配置保存在 cameras.json
  · 架构：支持 Windows / macOS / Linux
